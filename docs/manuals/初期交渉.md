## 概要

初期交渉は、候補者との信頼関係(ラポール)を構築し、今後のキャリアパートナーとして認知してもらうための最重要フェーズ。単なる「御用聞き」に終わらず、候補者の本音・深層心理にあるニーズを引き出し(ヒアリング)、ロンザン独自の価値ある情報・案件を「提案」することで、次回以降の交渉につなげる。

## 業務フロー

1. **導入・会社説明**
   - アイスブレイク
   - 「初期交渉投影資料」を用いてロンザン(レイスグループ)の事業内容・特徴・他社エージェントとの違いを説明
   - 候補者の流入経路(SMAP、転機など)に合わせた導入説明をスクリプトに沿って行う([[転機]]などチャネル別に説明の切り口を変える運用になっている点に注意)

2. **ヒアリング**
   - ヒアリングシート(候補者の属性別)を用いて経歴・実績・強みを引き出す
   - 「なぜ?」を繰り返し、転職検討理由・希望条件の真の動機(本音)を深掘り
   - 必須確認項目: 現在の年収・希望年収、家族構成・資産状況(ローン等)、人脈(知人・友人ネットワーク)
   - 半常勤・非常勤希望者は稼働可能頻度(週1〜3回など)を必ず確認

3. **提案**
   - 事前準備した「高訴求案件(初期交渉時使用)」やヒアリング内容にマッチする求人を提案
   - 候補者の市場価値を客観的な視点で提示

4. **クロージング・事務手続き**
   - 次回アクション(本交渉、書類修正、次回面談など)の合意
   - 「個人情報の取扱同意書」が未回収なら回収を徹底
   - 信頼関係が築けた場合はリファラル(知人紹介)を依頼

5. **実施後対応**
   - **RHS登録(重要)**: 「初期交渉実施報告」を速やかに行う。希望頻度などの入力欄を正確に埋める
   - お礼メール(プレイバックメール等)の送信
   - AIツール(Bring out、NotebookLM)を使った商談振り返り・フィードバック

## 使用ツール・システム

| 名称 | 用途 |
|---|---|
| RHS | 初期交渉実施報告・候補者ステータス管理システム。登録漏れは他営業とのバッティング(重複アプローチ)の原因になる |
| Bring out | Zoom面談のAI解析ツール(記録・分析) |
| NotebookLM | 録画データからのAIフィードバック・振り返り |
| 個人情報の取扱同意書 | 具体的な企業推薦・詳細案件情報の提供は原則この同意取得後に行う(コンプライアンス上の必須事項) |

## 注意点

- RHS登録を怠ると候補者ステータスが更新されず、システム上の不整合や重複アプローチの原因になるため、必ず当日中に登録する
- 半常勤・非常勤希望者の「希望頻度」入力漏れに注意
- 同意書未取得のまま具体的な企業推薦・詳細案件情報を進めない
