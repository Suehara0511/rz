# 業務マニュアル: マッチング/再交渉のポイント割り振りルール

出典: ロンザンポータル(Google Sites、本文はユーザーからの貼り付けで取得)。2024/04〜の改訂ルール、2026/08更新版。

[docs/business-structure.md](../business-structure.md) の「両手/片手」「顧客指示ポイント」の実際の配分ロジック(詳細版)。マッチング・再交渉に関わるKPI(件数・ポイント)が計画未達の場合、担当割り振りルールの複雑さ自体が原因(担当が付かない/貢献が正しく計上されない等)になっていないかを確認する際の一次情報として使う。

マッチング/再交渉した場合のポイント割り振りは、**事業部内マッチング**か**事業部またぎマッチング**かで規則が異なる。

## ケース1: 事業部内マッチングの場合(既存ルールから変更あり)

### 変更点(2024/04〜)

1. マッチング/再交渉ポイント分を「企業マッチング貢献(この企業に提案できるのでは？)」と「推進貢献(設定のやりとり、候補者担当としての推進)」に折半する
2. 候補者開放前のマッチングをNGとする(マッチングしたとしても初期交渉担当とAP獲得者にしか割り振りなし)

### 変更背景

1. マッチングの貢献をより詳細に明確にするため
2. 初期交渉担当のマッチングを促進させるため

### 用語定義

- **マッチング**(マッチング貢献ポイント付与対象): 案件向けに推薦可能な候補者を探索し企業担当に提案する活動。候補者への連絡などは行わない。**RHSのマッチング申請が必須**(業推はマッチングメールにてマッチング者を判断)。
- **案件説明・近況ヒアリング**(推進貢献ポイント付与対象): マッチングされた候補者・マッチングした候補者に連絡して再度電話や面談を行う活動(業推は本交渉の候補者担当にて推進担当者を判断)。
- **再交渉**: 初期交渉から90日以上経過した候補者の掘り起こし。再度、初期交渉のような動きをした場合のみ「再交渉」とする(案件につなぐだけの動きは再交渉に当たらない)。APソースが上書きされる場合(例: SMAP→転機)は、新ソースでの初回接触(例: 転機の初期接触)は再交渉ではなく**初期交渉**として扱う。

### ポイント割り振りの適用条件

- 候補者開放後(初期交渉から2週間以上経過後)にマッチングしている場合のみ適用
- 再交渉実施から1週間以内は、候補者(再交渉)担当以外は当該候補者のマッチングとしてカウントしない(ただし元候補者担当のマッチングはOK)。APソースに関わらず1週間。

### 割り振り率(候補者ポイントに対する割合)

| 担当 | ロンザン片手(候補者ポイント40%) | ロンザン両手(候補者ポイント30%) |
|---|---|---|
| 初期交渉担当 | 3% | 2.25% |
| マッチング担当 | 10.5% | 7.875% |
| 候補者推進担当 | 10.5% | 7.875% |
| 候補者獲得 | 16% | 12% |

レイノス候補者もAPソースに基づき仕入れポイントを付与する。仕入れ担当がいないソース(例: Gアポ、PDMアポ)の場合、仕入れなしで以下のように再配分する。

- 片手: 5% / 17.5% / 17.5%(マッチング担当/候補者推進担当/候補者獲得)
- 両手: 3.75% / 13.175% / 13.175%

## ケース2: 事業部またぎマッチングの場合(既存ルールから変更なし)

### 用語定義

- **マッチング**: 案件向けに推薦可能な候補者を探索し企業担当に提案するのみ。候補者への連絡などは行わない。
- **再交渉**: マッチングに加え、候補者に連絡を取り近況・最新の転職活動状況を確認する。提案文のアップデートや、必要に応じ履歴書・職務経歴書の最新版受領も行う。企業提案は自身で行っても企業担当から説明してもらっても構わないが、その後の候補者側の日程調整・前日確認連絡など候補者担当としての役割は全うすること。

### 適用条件

事業部内マッチングと同様(候補者開放後=初期交渉から2週間以上/再交渉実施から1週間は当該担当以外マッチング不可、APソース問わず)。

### 割り振り率

| 担当 | ロンザン片手(候補者ポイント40%) | ロンザン両手(候補者ポイント30%) |
|---|---|---|
| 初期交渉担当 | 3% | 2.25% |
| マッチング/再交渉担当 | 21%(内訳: SCマッチング担当12%+SC面談担当9%) | 15.75%(内訳: SCマッチング担当9%+SC面談担当6.75%) |
| 候補者獲得 | 16% | 12% |

SC内でマッチング担当・候補者面談担当が分かれている場合、SCのルールに則りマッチング/再交渉担当の取り分(21%または15.75%)を20:15の比率で分配する(2025/3/27追記)。

レイノス候補者、仕入れ担当がいないソース(例: Gアポ、PDMアポ)の場合、仕入れなしで以下のように再配分する。

- 片手: 5% / 35%(マッチング/再交渉担当/候補者獲得)
- 両手: 3.75% / 26.25%

## その他詳細ルール

1. レイノス・ロンザン両DBに候補者が存在し、マッチングが被った場合は、**メールの申請日時が早い方**のマッチングが適用される。
2. 特定企業へのマッチング/再交渉の有効期限は**3ヶ月(90日間)**。ただし、マッチング/再交渉し設定されたものが一度「オチ」て復活した場合は、期間をオーバーしていても、設定した際のマッチング/再交渉担当が適用される。

   **具体例**:
   - 例2: 2021/06/22 AさんがD社にマッチング → 06/25 設定したがオチ → 09/23〜 Aさん以外もD社にマッチング可能 → 10/23 BさんがD社に再度マッチング → 10/24 設定 → 2022/01/30 成約 → **マッチングポイントはAさんに付与**(設定時点のマッチング担当が優先されるため)
   - 例3: 2021/06/22 AさんがD社にマッチング → 06/25 設定できず → 09/23〜 Aさん以外もD社にマッチング可能 → 10/23 BさんがD社に再度マッチング → 10/24 設定 → 2022/01/30 成約 → **マッチングポイントはBさんに付与**(Aさんは設定に至っていないため、後発のBさんの設定時点のマッチングが優先される)
