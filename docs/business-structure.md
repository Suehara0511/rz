# ロンザン事業構造・KPI体系メモ

株式会社ロンザン(シニアエグゼクティブ層のスカウト・ヘッドハンティング事業)の経営会議議事録(2026/01/20〜2026/06/02、計12回分、Google Drive上の生データ・要約から抽出)を基にした事業構造・KPI体系の整理。経営企画としての予実管理・KPI悪化要因の仮説立案のための背景知識として、[CLAUDE.md](../CLAUDE.md)から参照される。

## 1. 事業の基本モデル

ロンザンの受注プロセスは大きく2つの役割に分かれる。

- **フロント**: 企業側の新規開拓・商談設定を担う上流部隊(いわゆる企業開拓軸)。ソースは「自活(自分でリスト作成・アプローチ)」「他部署ソース」「パートナー紹介」「PDM経由」などに細分化される。
- **ミドル**: 候補者側・企業側それぞれの担当(候補者担当/企業担当)に分かれ、候補者との初期交渉からマッチング・本交渉設定・成約までを担う(候補者集客〜成約軸)。

この2軸(企業開拓/候補者集客)が、ユーザーの認識通り会議でも一貫して別々に管理・報告されている。

## 2. 営業ファネル(KPIの連鎖構造)

一貫して以下の直列ファネルで管理されている(表記ゆれあり、後述)。

```
初期交渉 → (再交渉) → マッチング(実提案) → 設定(本交渉設定/対面商談設定) → 本交渉 → 成約
```

- **初期交渉**: 候補者との最初の接点・アポ。ミドル候補者担当やSMAP専任担当が担う。
- **再交渉**: 初期交渉から一定期間(目安半年)経過後、または別担当が改めて候補者とマッチングする活動。「マッチング数」は主に再交渉側でカウントされる。
- **マッチング(実提案)**: 企業に対して実際に候補者を提案した件数。「空撃ち・チャレンジ提案」という質を伴わない水増しのリスクが経営陣から繰り返し指摘されている。
- **設定(本交渉設定)**: 提案・マッチングが具体的な商談機会に転換すること。候補者側・企業側それぞれでカウントされ、両方成立する「両手設定」と片方のみの「片手設定」がある。
- **両手/片手**: 両手=候補者・企業の双方をロンザンが担当(自社完結、収益性が高い)。片手=どちらか一方のみロンザンが担当し、もう一方は提携エージェント「レイノス」等が担当。成果ポイントの具体的な配分率(初期交渉担当/マッチング担当/候補者推進担当/候補者獲得の内訳、事業部内マッチングと事業部またぎマッチングでの違いなど)は [docs/manuals/マッチング_再交渉.md](manuals/マッチング_再交渉.md) を参照。
- **成約**: 文字起こし上「制約」と誤記されることが多いが、文脈上ほぼ全て「成約」の意。

**経営陣(Shigenori Kita氏)が繰り返し強調する論点**: 「初期交渉・アポの絶対数はロンザンが完全にコントロールできる指標ではなく、量を追うだけでは意味が薄い。歩留まり(設定率・成約率)の絶対的な改善こそが本質」「上流(初期交渉)のプールが不足している状態で企業担当を増やしてもマッチング数は増えない、組織全体のバランスの問題」という、量から質(歩留まり)へのシフトを求める指摘が全期間を通じて一貫している。

## 3. 組織・役割一覧

| 名称 | 役割 |
|---|---|
| フロント | 企業側新規開拓・商談設定。ベテラン層は「化石(クラス)」と呼ばれることがある |
| ミドル候補者担当 | 候補者側の初期交渉・面談対応 |
| ミドル企業担当(緑企業担当) | 企業側とのマッチング・本交渉設定 |
| SMAP / SMAP専任担当 | 自社運営の候補者ソーシングチャネル。経営陣が直接コントロール可能なレバーとして重視 |
| 天気(転機) | 広告経由の候補者集客チャネル(転職支援サイト「転機」を指すと推定。KPI: Impression/CTR/CVR/CPA等はユーザーが別途管理) |
| エイサポ(Aサポ/営業サポート) | 企業への実提案・レポート作成を担う補助チーム。人員により機能縮小し候補者担当へ統合される時期があった |
| PDM | 電話対応が苦手なフロントメンバーの一時異動先(通称「留学」制度) |
| 半常勤 | 常勤ではない人員プール。候補者リスト充実や紹介・継続報酬の柔軟な配分対象。28期3Qより数字を別事業会社として分離管理 |
| レイノス | 提携先エージェント。候補者/企業の既存「枠」を保有し、ロンザンが決めた割合に応じて「リピートポイント」が配分される仕組み(例: 既存5枠中3枠をロンザンが決めた場合、新規発生分の5分の3がロンザン帰属) |
| 顧問メーカー契約 | フロントが開拓した案件のうちフロント自身が2人目・3人目も決めてよい特殊契約形態(その場合ポイントは目減り) |

## 4. KPI集計・報告の仕組みと既知の課題

- **クオーター比較の粒度**: 「全クォーター(前期)」「コンクォーター(今期)」「第◯クォーター」という3期比較が標準。営業日数(月により16〜20営業日など変動)で正規化。
- **着地見込み**: 週次で更新。「今読める確実な数字」なのか「将来の週別本交渉予定×確度別成約率(A/B/C読み)を織り込んだ予測」なのか、定義があいまいになりがちで、代表からの是正指示が複数回入っている。
- **顧客指示ポイント**: 年間・クォーター単位の金額ポイント計画(例: 全クォーター14.7億→今期21.7億)。
- **既知の構造課題(経営企画として特に重要)**: 事業計画シート・ロンザン進捗データ・生産性シート等、**複数の管理シートが並存し、締め日基準(金曜締めvs日曜締め)や営業日換算方法の違いから恒常的に数値の不整合が発生**している。会議の相当な時間が「なぜ数字が合わないのか」の原因究明に費やされており、KPI定義自体(初期交渉/再交渉/マッチング/設定/実提案の集計方法)もメンバー間でズレが生じやすい。KPI悪化の原因を仮説立てる際は、「本当の業務悪化」なのか「集計ロジック・締め日の違いによる見かけ上のズレ」なのかを最初に切り分ける価値が高い。「集計ロジックのズレ」の具体的な一例(代表セル数式のコピペミスにより内訳行の分母が全体と一致しなくなっていたケース)は [CLAUDE.md](../CLAUDE.md) の「KPI分析時の注意点」を参照。
